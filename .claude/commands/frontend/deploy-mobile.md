# Skill: Deploy Holefeeder to mobile device

Use this skill to deploy Holefeeder to my mobile device.

When executing this command, during the build you will be asked to choose which device; select `Patrick Moreau's iPhone`.

```bash
cd frontend/apps/holefeeder-mobile/ && pnpm run ios:deploy
```
